# VibeCoder Solutions

Step 1: HERO
1. Создай блок Hero блок: "Решения для вашего бизнеса" для лендинга специалиста вайбкодера.
2. Используй стиль загруженного референса, измени цветовую палитру на темно-зеленый.
3. Сделай 3 пакетных предложений для клиента: 1 Стартовый - Сайт приема заявок, обратной связи. 2 Продвинутый - Бот для общения, сайт и база данных. 3 Максимальный - Решение под ключ: Боты, сайт, база данных с возможностью + бизнес метрики. В подарок 1 ИИ ассистент (выдели дополнительным значком подарка)
В каждой карточке должно быть:
Название пакетного предложения
Краткое описание
Набор решений, который включает себя пакетное предложение
Небольшое превью (можно использовать плейсхолдер).
Карточки должны хорошо выглядеть на мобильных устройствах (располагаться вертикально). Остальное не трогай.
